# KOMITS Monitoring & Restructure Dashboard

Prototipe dashboard organisasi berbahasa Indonesia. Buka `index.html` langsung di browser atau jalankan server statis, misalnya `python3 -m http.server 8000`, lalu buka `http://localhost:8000`.

Data contoh dapat ditambah dan diedit di modul tabel dan disimpan di localStorage browser. Ekspor Excel menghasilkan CSV yang dapat dibuka di Excel; ekspor PDF menggunakan dialog cetak browser. Data dan grafik ringkasan adalah ilustrasi, bukan laporan keuangan aktual. Role dan alert adalah rancangan tampilan: prototipe ini belum menyediakan autentikasi, kontrol akses, sinkronisasi antar pengguna, penyimpanan server, atau deteksi notifikasi otomatis. Jangan masukkan data pribadi atau keuangan sebenarnya sebelum fitur keamanan dan backend diterapkan.
